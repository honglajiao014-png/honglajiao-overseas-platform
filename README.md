# Honglajiao Auto Export

**honglajiao.com** — Used Cars & Commercial Vehicles Export from China to Africa.

This is the **overseas public site** (海外独立站) for Honglajiao Auto Export, a China-based vehicle sourcing and export coordination service for African left-hand-drive markets.

> **This is NOT the domestic platform.** The domestic platform is at `/Users/mj/honglingjing-auto-platform` and is a separate project. This overseas platform reads only exported data files from `~/Desktop/已审核车源/` — it never connects to the domestic database.

## Quick Start

```bash
cd /Users/mj/honglajiao-overseas-platform

# Install dependencies
npm install

# Import vehicle data from domestic platform exports
npx tsx scripts/import_exported_vehicles.ts

# Start dev server (port 3001)
npm run dev -- -p 3001

# Production build
npm run build
```

## Project Structure

```
src/
  app/                    # Next.js App Router pages (13 routes)
  components/             # Shared UI components (11 components)
  data/vehicles.ts        # Vehicle data (auto-generated by import script)
scripts/
  import_exported_vehicles.ts  # Import vehicles from ~/Desktop/已审核车源/
public/vehicles/          # Imported vehicle images
```

## Key Features

- Vehicle listings with real images imported from domestic platform exports
- Vehicle detail pages with image gallery and full specs
- Inquiry form with vehicle prefill (`/inquiry?vehicleId=<id>`)
- SEO market guides for Africa, Nigeria, Ghana, Egypt
- Africa LHD markets reference page (33 countries)
- 46-country dropdown in inquiry form (LHD Africa prioritized)
- All prices displayed as "Contact for price" (domestic costs never exposed)
- Risk disclaimers on every page
- Mobile responsive, English-only, static generation

## Data Source

Vehicle data is imported from `~/Desktop/已审核车源/<vehicleId>/` which is exported by the domestic platform. Run the import script to sync:

```bash
npx tsx scripts/import_exported_vehicles.ts
```
